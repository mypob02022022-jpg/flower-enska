# Все цветы для Энска — премиальный одностраничный сайт

Учебный проект для вымышленного города Энск. Собран по скиллам
`local-business-website` и `frontend-design` с опорой на библиотеку `brand-library`.

## Структура

```
flower-premium\
├── index.html          — вся страница (10 секций + интерактивная SVG-карта Энска)
├── styles\style.css    — премиальная палитра, типографика, адаптив, анимации
├── scripts\script.js   — меню, карта с 90 домами, «Как добраться», reveal-анимации
├── images\             — фото (CC0, см. photos-meta.json), логотипы SVG
└── README.md
```

## Карта

Интерактивная SVG-схема Энска (без внешних API): 3 улицы × 30 домов
(Ленина, Маркса, Энгельса), 4 Бульварные, Пионерский пруд на севере,
сосновые леса на юге. Магазин — ул. Ленина, 13 (второй квартал). Кнопка
«Как добраться» прокручивает к карте и подсвечивает магазин.

## Фотографии

Все CC0 (общественное достояние), источники и авторы — в `images/photos-meta.json`.
Фото интерьера и фасада — иллюстративные. Unsplash и Pexels с этой машины
недоступны (сеть провайдера), поэтому использованы изображения Openverse/StockSnap
с лицензией CC0.

## Публикация (Beget)

Скопировать **содержимое** папки `flower-premium\` (index.html, styles\, scripts\,
images\) в `public_html`. Домен и SSL настраиваются в панели хостинга.
Ничего не публиковать без согласования.

## Домены-кандидаты (.ru)

Проверка — DNS-запрос; «NXDOMAIN» означает «скорее всего свободен», финальную
доступность подтверждает регистратор перед заказом. Ничего не регистрировалось.
См. раздел «Домены» в отчёте разработчика.
